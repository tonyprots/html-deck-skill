# Шрифты тем

Подмножества кириллицы и латиницы в WOFF2, по два файла на шрифт:

- Wix Madefor Display и Wix Madefor Text — вариативные, ось веса 400–800 («Клуб»);
- Geologica — вариативный, ось веса 100–900: подписи капителью «Клуба», весь «Графит»;
- Fixel Display — ExtraBold, подпись площадки на обложке «Клуба»;
- Commissioner — вариативный гротеск: «Тетрадь», «Калька», «Школа», «Синька»;
- Tektur — технический дисплейный: «Калька», «Синька»;
- Martian Mono — моноширинный для кода: «Калька», «Синька»;
- рукописные для пометок: Caveat («Тетрадь»), Marck Script («Школа»),
  Pangolin («Графит»), LXGW WenKai TC («Калька», «Синька»).

Все распространяются по SIL Open Font License 1.1, тексты лицензий с
копирайтами — в `licenses/`. `apply-theme.py` вшивает нужные теме файлы в
деку как data-URI, выкладывать их отдельно не нужно.
