# Темы

Тема меняет только значения токенов и шрифты, компоненты шаблона не
трогает. Накладывается одной командой сразу после копирования шаблона:

    python3 scripts/apply-theme.py index.html themes/<тема>

По умолчанию дека светлая. Шрифты темы вшиваются в деку, внешних загрузок нет.

| Тема | Характер | Шрифты | Когда брать |
|---|---|---|---|
| без темы | нейтральная: белый, глубокий зелёный акцент | New York (на Windows — Georgia) + системный гротеск | когда тема не нужна или дека уйдёт в чужой шаблон |
| `club` · Клуб | белая сцена, синий акцент, лаймовые заливки, мазок кисти лаймом под главным словом | Wix Madefor Display + Wix Madefor Text, подписи — Geologica, площадка на обложке — Fixel Display | по умолчанию для доклада и внешнего выступления; подходит почти к любому жанру |
| `notebook` · Тетрадь | бумага в точку с зеленцой, зелёные чернила; блоки — вклеенные листы, вывод — лаймовый стикер | Commissioner, пометки Caveat | исследование, аналитика, стратегия |
| `draft` · Калька | чертёжная сетка, синие чернила, заголовки капсом; блоки — контуры, вывод — пунктирная рамка | Tektur + Commissioner, код Martian Mono | архитектура, устройство системы, инженерный доклад |
| `school` · Школа | тетрадь в линейку с красным полем; вывод обведён красной ручкой | Commissioner, пометки Marck Script | обучение, онбординг, лекция |
| `graphite` · Графит, тёмная | тёплый графит, лаймовый акцент | Geologica, пометки Pangolin | финансы, метрики, сцена в тёмном зале |
| `blueprint` · Синька, тёмная | чертёжный синий, жёлтые пометки; тёмный вариант «Кальки» | Tektur + Commissioner, код Martian Mono | инженерия в тёмном зале |


Подробности темы, её характер и контраст — в `THEME.md` в её папке.

## Своя тема

Своя тема (компании, площадки, серии докладов) — папка `themes/<имя>/`:

- `theme.css` — блок `:root` с новыми **значениями** тех же токенов, при
  нужде `@font-face` со ссылками на `../_fonts/*.woff2`. Имена токенов не
  меняются. За образец удобно взять `club/theme.css`.
- `logo.svg` — по желанию: встаёт в подвал и в центр бенто.
- `THEME.md` — когда брать, характер и таблица контраста.

Токены характера: `--font-serif` и `--display-*` (заголовок), `--font-label`
(подписи капителью), `--font-kick` (подпись площадки на обложке),
`--stage-pattern` (фон сцены), `--mk-shadow` / `--mk-deco` / `--mk-bg`
(маркер: заливка, подчёркивание или мазок-картинка), `--font-hand` и
`--hand-*` (пометка от руки), `--ring-ink` (обводка `.hand-ring`),
`--main-tile-bg` / `--main-tile-ink` (главная плитка бенто), `--acc2`
(второй цвет). Форма блоков: `--block-*` (карточки, квадраты, круговая,
уроки, шаги — заливка, рамка, тень, скругление), `--tk-*` (вывод слайда,
включая шрифт `--tk-font`), `--bento-bg` и `--tile-*` (бенто). Без них
тема меняет только цвет, а блоки во всех темах выглядят одинаково.

После наложения темы пересчитать контраст каждой пары: текст от 7:1, подписи,
текст акцентом и текст на акцентной заливке от 4,5:1, крупные числа и линии
от 3:1. `audit-browser.js` ловит `contrast` на живой деке. Тему площадки
делать по `references/layout-rules.md`, «Тема площадки».

Тёмные темы — «Графит» и «Синька» — только по явной просьбе автора
(«тёмная», «для сцены», «тёмный зал»). Тёмная дека — всегда темой целиком с
`color-scheme:dark`, не тёмными плашками в светлой.
