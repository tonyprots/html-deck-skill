# Какой компонент под какое содержание

Разметка и CSS каждого компонента — в `assets/template.html`, там каждая
секция подписана комментарием. Здесь — выбор.

Главный блок слайда ставится с классом `.grow`. Карточки, матрица и «Кто я»
с ним тянутся на высоту тела, кегль внутри растёт. Таблица, таймлайн,
квадраты и круговая не тянутся: растянутая таблица раздувает шапку и строки,
растянутый квадрат даёт дыру между иконкой и подписью. Они растут масштабом:
крупнее кегль и поля, а место заполняют строки и содержимое (четвёртая
строка таблицы, доли в легенде, метки в квадрате).

| Содержание | Компонент | Замечания |
|---|---|---|
| Начало раздела | `.divider` | 108 px антиква, тезис раздела, оглавление внизу с `.cur`; 4–5 разделов на деку |
| Два сопоставимых понятия | `.cards.c2` под лидом с двоеточием, `.body.follow` | второе можно `.warm`, если «это про нас» |
| Два понятия + одна шкала | `.cards.c2` + `.bars` | подпись шкалы `.bars-h` обязательна; ширина заливки = числу |
| Три сегмента или уровня | `.cards.c3` с тегами, `.body.airy` | у всех тег, сноски `.ms` на одной линии |
| Четыре ступени рынка | `.cards.c4` + чипы игроков | самый плотный вариант, кегль 12,5; проверять «одна строка» у чипов |
| Наша модель поверх чужой | `.steps2` лесенка | пилюля → стрелка с условием → пилюля; ступени выровнены |
| Две компании × две линии бизнеса | `.matrix` | подписи строк повёрнуты, мост стрелками SVG |
| 3–5 игроков по 2–3 признакам | `table` | линейки только горизонтальные, первая колонка жирная, важное `.m` |
| История одного процесса | `.tl` таймлайн | одна строка на игрока, статус справа `.end` с подстрокой `u` |
| Крупная цифра с контекстом | `.card.warm` + `.big` | цифра `--measured-deep`, единица `small` |
| Вывод слайда | `.note.takeaway` | необязателен (правило 2); если есть — последний в `.body`, блок в рамке, одна фраза, `b` в первом предложении |
| 3–4 коротких равных сущности (провайдеры, варианты) | `.sq4` квадраты | иконка `.bi`, имя, одна сноска `.ms`; наши — `.warm` |
| Состав целого: доли и итог | `.donut` | SVG-кольцо, `pathLength` = итог, `stroke-dasharray` = доля; легенда с числами справа; не столбики |
| Выделить один блок (база, источник, обзор) | `.card.dash` | белый с пунктиром акцента; не тёмная плашка |
| Ссылки (скилл, канал, вики) | `.links` | светлые чипы одного цвета, призыв серым внутри |
| Уроки раздела в докладе | `.lessons` 2×2 + `.links` сверху | заголовок «Что забрать…» или «Уроки …», без вывода внизу |
| Цитата | `.note.quote` | имя и роль, цветом чернил |
| Доклад: «Кто говорит» (второй слайд) | `.who` + `.svc-g` | слева роль и канал, справа 4–6 сделанных вещей `.sv` с цифрой `em`; два главных — `.sv.warm.hero` в первом ряду; только реальное |
| Доклад: «Что сделать в первую очередь» | `.first` = `.fs` + `.skl` | 3–4 шага повелительно, последний может быть `.warm`; справа ссылки, которые зал фотографирует; перед бенто итогов |
| Доклад: «Спасибо» (последний) | `.slide.thanks` | крупный призыв подписаться на канал в `.card.warm.cta`, остальные ссылки рядом; лид — главная мысль на прощание |
| Выделить два-три слова в лиде или тексте | `.mk` маркер | вид задаёт тема (`--mk-shadow`, `--mk-deco`): заливка, подчёркивание, обводка, волна; не больше одного на слайд |
| Второй цвет рубрики (другой сегмент, «не наше») | `.tag.alt` | подложка из `--acc2` темы; в теме без второго цвета совпадает с основным акцентом |
| Пометка от руки — реплика докладчика к блоку | `.hand` (+ `.hand-arrow`) | шрифт и цвет — от темы; одна на слайд; в потоке над блоком, на который указывает; `.hand.pin` — только в заведомо пустом месте, проверять `hand-overlap` |
| Итог деки | `.bento-slide` | 6×4, тезисы равноценны, без заголовка «Главное»; в центре логотип или, в докладе, главная мысль `.tile.main` + `.bmain` («Нет ничего невозможного с ИИ»), вокруг — выводы разделов |

Чего в шаблоне нет намеренно: тёмных карточек и тёмных кнопок (тёмная
дека — только темой целиком из `themes/`), градиентов, теней, иконок в плитках-квадратах, заметок спикера.

Нужного компонента нет — сначала добавить его в `assets/template.html` и
в эту таблицу в стиле палитры, потом использовать. Чёрные кнопки и плашки
на одном докладе появились именно так: компонента для ссылок не было, и агент
придумал свой стиль на одной деке.
